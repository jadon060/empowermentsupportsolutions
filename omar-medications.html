🚦 ESS Refill Workflow

Use these prompts so a refill is handled before the medication supply runs out.

🔵 Set up / verify count

If the count is blank, count the pills and save the current quantity. The page cannot estimate a refill date without a reliable starting count.

🟡 7 days or fewer estimated

Start the refill process: notify ESS management/family as appropriate, contact the pharmacy, and document the request. Check whether refills remain.

🔴 3 days or fewer / 0 refills

Escalate the refill the same day. Contact the pharmacy/prescriber or authorized responsible party. Do not change the dose or substitute medication to stretch the supply.
